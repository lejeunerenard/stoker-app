# Stoker App

An app for tracking and controlling a stoker for grills & smokers.

## Development Setup

Need Node.js, `npm` & [`pear`](https://docs.pears.com/guides/getting-started) installed.

### Setup

```console
npm install
```

### Building spec

```console
npm run build
```

### Running

```console
pear run -d .
```

### Testing

```console
npm test
```
